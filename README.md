# VVitCutLER

## Install
please install all package in install.sh

## Datasets Preparation

We handles datasets as in Detectron2. You should set the location for builtin datasets by export DETECTRON2_DATASETS=/path/to/datasets. If left unset, the default is ./datasets relative to your current working directory.

please download the ImageNetVID in [here](https://image-net.org/challenges/LSVRC/2015/index), please in the struture like this:
imagenetvid/
├── train/
│   ├── ILSVRC2015_train_00000000/*.JPEG
│   ├── ILSVRC2015_train_00000001/*.JPEG
│   └── ...
├── val/
│   ├── ILSVRC2015_val_00000000/*.JPEG
│   ├── ILSVRC2015_val_00000001/*.JPEG
│   └── ...
└── annotations/
    ├── imagenet_vid_train.json
    └── imagenet_vid_val.json  # generated by VoteCut
